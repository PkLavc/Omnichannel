# Roadmap

- [x] Gateway, Chatwoot, PostgreSQL/pgvector, Redis, Admin e n8n em containers.
- [x] Webhook/resposta Chatwoot, memória, RAG, fallback de providers, logs e transferência humana.
- [x] Identidade genérica, configuração operacional persistida, Wizard inicial, gestão de RAG, Tools configuráveis e scripts Windows.
- [ ] Hardening de produção: assinatura HMAC nativa e rotação do segredo do webhook, fila durável/distribuída, MFA/provedor de identidade e integração com secret manager.
- [ ] Embeddings neurais opcionais sem tornar Ollama obrigatório.
- [ ] Adapters específicos conforme forem disponibilizados contratos de estoque, produtos, garantia, OS, clientes e agendamento.
- [ ] Escalabilidade horizontal, métricas agregadas, tracing, dashboards, alertas e recuperação de desastre testada regularmente.
