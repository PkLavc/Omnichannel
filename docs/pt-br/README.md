# Documentação — Português do Brasil

## Atalhos do painel

Depois de entrar em `http://localhost:3002`:

- crie ou selecione a empresa ativa antes de alterar qualquer configuração tenant-scoped;
- use **IA e providers / chaves** para cadastrar uma ou mais credenciais globais, definir `ALL` ou `SELECTED`, salvar e testar;
- use **Conhecimento / RAG** para importar manualmente um documento da pasta privada da empresa somente no tenant selecionado;
- use **Operação** para verificar provider, fallback, latência, tokens e logs das conversas.
