# Roadmap

- [x] Containerized Gateway, Chatwoot, PostgreSQL/pgvector, Redis, Admin, and n8n.
- [x] Chatwoot webhook/reply, memory, RAG, providers with fallback, logs, and human handoff.
- [x] Generic branding, persistent operational configuration, first-use wizard, RAG management, configurable Tools, and Windows scripts.
- [ ] Production hardening: native HMAC signing and webhook-secret rotation, durable distributed queue, MFA/identity-provider integration, and secret manager integration.
- [ ] Optional neural embeddings without making Ollama mandatory.
- [ ] Vendor-specific Tool adapters as inventory, product, warranty, service-order, customer, and scheduling API contracts become available.
- [ ] Horizontal scaling, aggregate metrics, tracing, dashboards, alerts, and regularly tested disaster recovery.
