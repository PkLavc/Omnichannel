# Documentation — English

## Admin shortcuts

After signing in at `http://localhost:3002`:

- create or select the active company before changing any tenant-scoped configuration;
- use **AI and providers / keys** to register one or more global credentials, choose `ALL` or `SELECTED`, save, and test;
- use **Knowledge / RAG** to import a document from that company's private folder manually into the selected tenant only;
- use **Operations** to inspect the provider, fallback, latency, tokens, and conversation logs.
